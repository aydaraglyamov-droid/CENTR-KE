ИИ-агенты продвижения

Нажмите на агента — через 2 секунды он выдаст отчет на основе текущих реальных данных дашборда.

Настройки подключений

Ключи хранятся только в вашем браузере (localStorage) и никуда не отправляются, кроме официальных API соцсетей.

YouTube Data API v3

Получить: Google Cloud Console → включить YouTube Data API v3 → создать ключ.

VK API

Получить: dev.vk.com → создать приложение → «Сервисный ключ доступа». Запросы идут через JSONP (работает без сервера).

Telegram Bot API

Получить у @BotFather. Бота нужно добавить в канал как администратора, чтобы он видел число подписчиков.

Яндекс.Музыка

Публичного API статистики у Яндекс.Музыки нет — встроится официальный плеер исполнителя.
