Какие события уходят в Метрику

    Названия целей совпадают с именами событий — создайте цели типа «JavaScript-событие» с этими идентификаторами в интерфейсе Метрики, чтобы видеть конверсии.

    ИИ-агенты продвижения

    Агент разбирает текущие реальные данные дашборда и умную ссылку релиза и выдает отчет.

    Настройки подключений

    Ключи хранятся только в этом браузере (localStorage) и уходят лишь в официальные API площадок.

    BandLink

    Взять из адреса ссылки в кабинете BandLink. Данные релиза (обложка, площадки) подтягиваются автоматически.

    Яндекс.Метрика

    Номер виден в списке счетчиков. Значение здесь включает счетчик только в этом браузере — чтобы считать всех посетителей, задайте переменную окружения YANDEX_METRIKA_ID в настройках проекта Netlify.

    YouTube Data API v3

    Получить: Google Cloud Console → включить YouTube Data API v3 → создать ключ.

    VK API

    Получить: dev.vk.com → создать приложение → «Сервисный ключ доступа». Запросы идут через JSONP, сервер не нужен.

    Telegram Bot API

    Получить у @BotFather. Бота нужно добавить в канал администратором, чтобы он видел число подписчиков.

    Яндекс Музыка

    Число из адреса music.yandex.ru/artist/… Подставляется автоматически из умной ссылки. Публичного API статистики у сервиса нет — встраивается официальный плеер.
